# Customer Behavior Analysis

## Overview

This project analyzes customer shopping behavior to understand purchasing patterns across **customer demographics, product categories, and Order and transaction information** such as customerId and payment methods.

The project follows an end-to-end data analysis workflow starting with data preparation and exploratory analysis in **Python** followed by business analysis using **MySQL and SQL** and ending with an interactive **Power BI dashboard**.

The main goal is to answer key business questions and identify patterns that can help a retail company better understand its customers and sales performance.


## Dataset

The dataset contains customer shopping and transaction information, including details related to:

* Customer demographics
* Product categories
* Purchase amounts
* Customer purchasing behavior
* Order and transaction information

The dataset was sourced from **Kaggle** and was used for data cleaning, analysis, SQL querying, and dashboard development.


## Tools & Technologies

* **Python** — Data cleaning and exploratory data analysis
* **Pandas** — Data manipulation and preprocessing
* **MySQL** — Data storage and SQL analysis
* **SQL** — Business analysis and querying
* **Power BI** — Interactive dashboard and data visualization
* **Jupyter Notebook** — Python analysis environment


## Project Steps

### 1. Loading the Dataset into Python

The dataset was loaded into Python using **Pandas**.

Initial data inspection was performed to understand the structure and quality of the dataset.

This included:

* Loading the dataset
* Checking the number of rows and columns
* Reviewing column names
* Checking data types
* Inspecting the first few records
* Generating summary statistics


### 2. Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to understand customer behavior and identify patterns within the data.

The analysis examined

* Customer demographics
* Purchasing patterns
* Product category performance
* Purchase amounts
* Customer purchasing behavior


### 3. Data Cleaning

The dataset was cleaned and prepared for further analysis.

The cleaning process included:

* Identifying missing values
* Filling missing numerical values using the **median**
* Renaming columns for consistency and readability
* Checking for inconsistent or invalid values
* Preparing the final dataset for SQL analysis

Using the median to fill missing numerical values helped reduce the impact of extreme values and maintain the overall distribution of the data.


### 4. Importing Data into MySQL

After cleaning the dataset in Python, the prepared data was imported into **MySQL**.

MySQL was used to store the cleaned dataset and perform structured business analysis using SQL.


### 5. SQL Business Analysis

SQL queries were written to answer key business questions related to customer behavior and retail performance.

Examples of business questions include:

* What is the total revenue generated by male vs females?
* Which customers used a discount but still spent more than the average purchase amount?
* Compare the average Purchase Amount between Starndard and Express Shipping.
* Do subscribe customers spend more? Compare average spend and Total revenue between subscribers and non-subscribers.
* Which products have the highest percentage of purchase discounts applied?
* Segmant customers into New, Returning, Loyal based on their total number of previous purchases, and show count of each segment. 
* What are the top 3 most purchase products within each category?
* Are customers who are repeat buyers( more than 5 previous purchases) also likely to subscribe?
* What is the revenue contribution of each age group?

SQL aggregation, filtering, grouping, sorting, and conditional logic were used to answer these questions.


### 6. Power BI Dashboard

The results from the analysis were used to create an interactive **Power BI dashboard**.
The dashboard provides a visual overview of customer behavior and sales performance.

Key dashboard metrics and visualizations include

* Total Customers
* Total Purchases
* Average Purchase Amount
* Sales by Product Category
* Customer Demographics 
* Purchase Trends
* Customer Segment Analysis

Interactive filters and slicers allow users to explore the data from different perspectives.

## Results & Insights

The analysis provides a clear understanding of customer purchasing behavior across different demographics, product categories, and order and transaction information.

Key insights include:

* Identifying purchasing patterns across customer groups
* Understanding which product categories attract the most purchases
* Identifying differences in average purchase amounts
* Highlighting customer segments with different purchasing behaviors
* Using SQL analysis to answer specific business questions
* Presenting the findings through an interactive Power BI dashboard

The combination of **Python, SQL, and Power BI** transforms the raw customer transaction data into a structured analysis that can support data driven business decisions.
